# Proyecto de Prácticas y Avances de Ingeniería

Repositorio de almacenamiento para actividades, ejercicios de código y prácticas de programación desarrolladas durante el semestre académico.

## 🛠️ Tecnologías Utilizadas
- **Lenguajes:** Python 3, T-SQL / Bash
- **Entorno de Desarrollo:** macOS / VS Code
- **Control de Versiones:** Git & GitHub

## 📁 Estructura del Proyecto
- `src/`: Códigos fuente de ejercicios prácticos y utilidades.
- `docs/`: Apuntes y documentación técnica complementaria.
- `scripts/`: Automatización de tareas e interactividad.
